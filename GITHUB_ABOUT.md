## Description（中文）

面向 llama.cpp 与 OpenAI 兼容 Agent 的 KV 前缀缓存中间件。自动识别稳定的系统提示词、开发者提示词和工具列表，将 llama.cpp slot KV 快照持久化到磁盘，并在模型重启或 Agent 切换后恢复复用。

## Description (English)

Persistent KV prefix caching middleware for llama.cpp and OpenAI-compatible agents. It detects stable system/developer prompts and tool definitions, persists llama.cpp slot snapshots, and restores them after model restarts or agent switches.
