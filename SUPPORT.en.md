# Support

English | [简体中文](SUPPORT.md)

Read [README.en.md](README.en.md) and the [technical documentation](docs/TECHNICAL.en.md) first.

When opening a support request, include the Python version, llama.cpp build information, a redacted configuration based on `config.example.yml`, a request summary, and relevant log events. Do not upload models, KV snapshots, full system prompts, tool schemas, API keys, or machine paths.

For security issues, follow [SECURITY.en.md](SECURITY.en.md) instead of opening a public Issue.
